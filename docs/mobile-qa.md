# 移动端检查与回归步骤

本轮使用浏览器视口检查，覆盖 320、390、768px 宽度下的项目概览、费率扫描、交易样本、策略设计和工程说明。视口检查不等同于 iOS / Android 真机验证。

## 修复的问题

- 扫描页搜索框固定宽度在 320px 视口撑宽页面：改为小屏占满可用宽度，大屏保留原宽度。
- 小屏导航需要横向滚动才能找到工程说明：改为五列导航，直接显示全部入口。
- 首页标题在窄屏将「让套利决策」拆为两行：改用随视口缩放的字号。
- 小屏收益周期按钮与部分筛选按钮点击区域偏小：最小高度调整为 44px，周期按钮同时保留最小宽度。
- 曲线原先主要响应指针移动：增加按下选点，触摸指针离开后保留选点，鼠标离开仍恢复最新点。
- 小字号搜索输入在移动 Safari 可能触发聚焦放大：小屏文本输入统一为 16px。

## 手动回归清单

| 检查 | 预期结果 |
| --- | --- |
| 逐页切换并检查页面宽度 | 页面宽度不超过视口；行情表只在自身容器内横向滚动 |
| 查看顶部导航 | 五个页面入口完整显示，可点击切换 |
| 搜索 BTC | 表格保留 BTC，隐藏不匹配交易对 |
| 清空搜索并选择已过滤 | 显示 DOGE、ADA、DOT、LTC 四个过滤样本 |
| 左右滑动行情表 | 可以查看最右侧的套利池状态和过滤原因 |
| 切换 7D / 14D / 30D | 按钮选中状态、曲线点数和收益指标随窗口更新 |
| 点击收益曲线中部 | 选中点、日期和累计收益更新 |
| 聚焦曲线并按左右方向键 | 选点在窗口内逐日移动，不触发页面横向滚动 |
| 筛选进行中交易 | 显示两笔进行中仓位；切回全部恢复样本 |
| 点击查看更多样本 | 列表扩展，剩余数量减少 |

合成账本和演示边界仍由 `npm test` 验证；TypeScript 与静态生产构建由 `npm run build` 验证。
